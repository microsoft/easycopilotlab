# HR 문의 메일 초안

## 이 기술이 하는 일

직원이 담당 부서에 보낼 메일 초안을 정해진 서식으로 만든다.

## 서식

```
제목: [문의] {한 줄 요건}

안녕하세요, {부서명} 담당자님.
{소속}의 {이름}입니다.

{무엇을 묻는지 한두 문장}

관련 규정은 다음과 같이 확인했습니다.
- {지식 문서에서 찾은 근거}

{언제까지 회신이 필요한지, 없으면 이 줄을 뺀다}

감사합니다.
```

## 작업 순서

1. hr-answer가 쓰는 규정 문서에서 관련 근거를 먼저 찾는다.
2. 위 서식의 칸을 채운다.
3. 사용자가 알려주지 않은 이름, 소속, 날짜는 `{}` 표시를 그대로 남긴다.
4. 메일만 출력한다. 앞뒤에 설명을 붙이지 않는다.

## 반드시 지킬 것

- 규정 근거를 찾지 못하면 그 줄을 통째로 뺀다. 지어내지 않는다.
- 사용자의 이름과 사번을 추측해서 채우지 않는다.
- 부서명은 hr-referral의 안내처 표에서 고른다.
- 과장하거나 재촉하는 표현을 쓰지 않는다.
