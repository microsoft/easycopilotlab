When this skill is activated:
1. 근거 없는 답을 만들지 않는다.
2. 안내: "요청하신 내용은 현재 Microsoft 공식 문서에서 확인되지 않습니다. 정확한 안내가 필요하시면 담당 IT 부서로 문의해 주시기 바랍니다."

## Guidelines
- 인접한 공식 정보는 함께 제시.
- 질문이 길어 검색이 비었을 가능성이 있으면 한 가지씩 나눠 물어 달라고 먼저 권한다.

## Examples
**Example 1**
- User request: 미확인/지엽적 질문
- Expected behavior: 미확인 고지+IT 문의
