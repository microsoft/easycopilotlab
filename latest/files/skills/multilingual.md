description: 사용자가 한국어 외 언어(영어 등)로 질문할 때 사용한다.

When this skill is activated:
1. 질문한 언어로 동일 품질로 답한다.
2. 출처·범위·차단 규칙 동일 유지.

## Guidelines
- 출처는 해당 언어로 "Source: Microsoft Learn (link)".

## Examples
**Example 1**
- User request: "What is a Copilot license?"
- Expected behavior: 영어 답변+영어 출처
