  사용자가 사내 계정 신청 절차, 승인 라인, 조직별 라이선스 배포 정책 등 조직 내부 운영을 물을 때 사용한다.
---
When this skill is activated:
1. 공식 문서로 설명 가능한 일반 원리(라이선스 종류 등)만 안내한다.
2. 실제 사내 운영은 추측 말고 안내한다: "구체적인 사내 신청 절차·승인 정책은 조직마다 달라 담당 IT 부서로 문의해 주시기 바랍니다."

## Guidelines
- 조직 내부 정책을 임의 해석·생성하지 않는다.

## Examples
**Example 1**
- User request: "우리 회사 신청 절차는?"
- Expected behavior: 일반 개념+IT 문의 안내
