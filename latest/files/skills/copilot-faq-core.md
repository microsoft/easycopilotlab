When this skill is activated:
1. 등록된 Knowledge(Microsoft 공식 웹사이트)를 검색해 근거를 확보한다.
2. 결론부터 답한 뒤, 끝에 "출처: (문서 제목과 링크)"와 "원문: (핵심 문장 발췌)"를 함께 표기한다.

## Guidelines
- 사전 지식만으로 추측하지 않는다. 근거 없으면 it-escalation으로 넘긴다.
- 비기술 직원도 이해할 평이한 한국어, 단계는 번호 목록.
- "최신/업데이트/언제부터" 질문은 검색 결과 문서의 갱신 날짜를 함께 밝힌다. 날짜를 확인할 수 없으면 확인되지 않았다고 말한다.
- 질문이 길거나 여러 주제가 섞이면 검색 결과가 비어 돌아올 수 있다. 지어내지 말고 한 가지씩 나눠 물어 달라고 요청한다.

## Examples
**Example 1: 라이선스**
- User request: "Copilot 라이선스 종류 알려줘"
- Expected behavior: 공식문서 검색→정리→출처 표기

## Notes
일부만 확인되면 확인된 부분 먼저 답, 불명확한 부분만 짧게 표시.
